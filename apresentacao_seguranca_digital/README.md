# Apresentação Python - Segurança Digital

Apresentação educativa para o projeto de extensão de Sistemas de Informação e Sociedade.

## Conteúdos

Golpes virtuais, phishing, links suspeitos, senhas seguras, autenticação em dois fatores, proteção de dados pessoais, o que fazer após um golpe e um quiz de fixação.

## Como executar no Windows

1. Extraia esta pasta.
2. Abra a pasta `apresentacao_seguranca_digital`.
3. Clique na barra de endereço do Explorador de Arquivos.
4. Digite `powershell` e pressione Enter.
5. Digite:
   `python app.py`
6. Pressione Enter.

Se `python app.py` não funcionar, tente:
`py app.py`

Também existe o arquivo `abrir_apresentacao.bat`: basta dar dois cliques nele.

## Navegação

- Próximo: botão, seta direita ou Espaço
- Anterior: botão ou seta esquerda
- Tela cheia: F11
- Sair da tela cheia: Esc

## Importante

Este programa não precisa de Flask nem de bibliotecas externas. Ele usa somente Python + Tkinter.

O quiz e o dashboard do projeto Flask continuam sendo sistemas separados: esta aplicação é a parte de apresentação dos conteúdos.
